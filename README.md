Exactly one word for home Wi-Fi, as lived: it left without saying goodbye. Written after scoring eight fresh candidates against the judge's criteria (one word describing Wi-Fi as lived, funny at once, true to home Wi-Fi, avoids the obvious words, works with no context); the winner scored 23/25 and was revised once before submission.

## Run it

```bash
python3 main.py
```

This writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
